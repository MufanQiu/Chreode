# ICLR reproduction

The current release separates temporal pretraining, adaptation, intervention and
native spatial prediction. Commands in the legacy release guide use older
representations and evaluation protocols.

## Data and weights

Use the checksum-locked downloader in the main README. Omitting model and dataset
filters downloads the complete release. Model IDs and immutable source revisions
are listed in `releases/iclr2027.json`.

| Dataset directory | State | Prediction task |
|---|---|---|
| `weinreb` | Frozen 128D encoder | Day 2 to days 4 and 6 |
| `veres` | Frozen 128D encoder | Snapshot 0 to snapshots 1 through 7 |
| `zestaspatial` | Frozen 128D encoder, spatial metadata | 3.3 hpf to five later stages |
| `cytokine` | Frozen 128D encoder, condition and lineage metadata | Shared day-2 source to nine condition/time targets |
| `rectangle` | Native 3D gene state, 2D position | Known-alignment simulation, time 0 to 2.5 |

The released benchmark arrays are identical to the evaluation sources. JSON
manifests remove private path metadata while preserving source hashes, row order
and split contracts. Raw biological datasets retain their accession and license
requirements; this release distributes the processed benchmark states.

## Temporal evaluation

The evaluation protocol fixes the original scoring count at every target.
The default replay mode scores the released original prediction clouds with
deterministic population selection, training-only standardization, the exact
float64 transport solver and kernel metrics. It does not run model inference.
The sampling arm label stays `temporal` because it determines the published
subsampling seed. It is not inferred from a filename.

```sh
python -m cellworldmodel.script.score_release \
  --directory artifacts/iclr2027 \
  --protocol releases/iclr2027-evaluation.json \
  --dataset zesta --seed 0 --mode replay --device cpu \
  --output output/zesta-seed0.json --check-reference
```

Run each seed separately. Average target scores within a seed, then compute the
mean and sample standard deviation across the three seeds. `--check-reference`
checks W2 against the original full-precision score with absolute tolerance
0.0001. Use `--mode predict` to generate fresh populations from the checkpoint
instead. The original predictions were generated on a CUDA Blackwell GPU, then
scored on CPU. Use `--mode predict --device cuda` for that generation protocol.
CPU and CUDA generators produce different noise for the same nominal seed;
fresh predictions are labeled separately from archive replay.
Floating-point behavior on other devices is not assumed identical.
This command evaluates Chreode. External baselines retain their own training
implementations and supply clouds to the same metric functions.

## Temporal adaptation

Training requires an editable Git checkout so the provenance recorder can bind
the active source. Set the representation directory explicitly:

```sh
export CWM_PAPER_BENCH_REPRESENTATION_ROOT="$PWD/artifacts/iclr2027/data"
export CWM_PAPER_BENCH_STANDARDIZE_METRICS=1
python -m cellworldmodel.script.run_intermediate_eval \
  --experiment g2a_m10_wdit_time2vecu_lowfreqcurl_uncertainty_adamw \
  --dataset paper_weinreb_scvi128 --seed 0 --split-seed 42 \
  --epochs 20000 --lr 0.0003 --dit-size small \
  --wdit-time-delta-scale 19 --wdit-curl-time-delta-scale 19 \
  --init-checkpoint artifacts/iclr2027/models/dynamics.pt \
  --init-min-match-ratio 1 --output-dir output/weinreb-pretrained-seed0 \
  --save-checkpoint --val-every 100 --validation-metric val_w2_mean \
  --validation-source-subsample 512 --validation-max-target 1024 \
  --validation-max-preds 1024 --early-stopping-patience 800 \
  --early-stopping-min-delta 0.001 --log-every 100 \
  --transport-objective sinkhorn_divergence --transport-blur 0.05
```

The named experiment provides batch size 512, eight samples per source, the
four-term objective with uncertainty weighting and uniform ordered training pairs.
The accepted recipes are:

| Dataset argument | Initialization | Learning rate | Composition weight |
|---|---|---:|---:|
| `paper_weinreb_scvi128` | pretrained or scratch | 0.0003 | 0 |
| `paper_veres_scvi128` | pretrained | 0.0003 | 0 |
| `paper_veres_scvi128` | scratch | 0.0001 | 0 |
| `paper_native_zestaspatial` | pretrained | 0.0001 | 0.3 |
| `paper_native_zestaspatial` | scratch | 0.0003 | 0 |

For scratch, omit `--init-checkpoint` and its match-ratio option. Set
`--lambda-comp 0.3` for the selected pretrained ZESTA recipe. The composition
loss is unbiased population MMD on direct and two-hop raw states, with an adaptive
four-bandwidth kernel. It does not pair individually measured cells.

Budget curves add `--training-fraction 0.05` (or 0.1, 0.25, 1) and
`--checkpoint-updates 500 1000 2000 5000`. These checkpoints continue after early
stopping while preserving the already selected best-validation state. Evaluate
raw weights at each budget; do not substitute the best checkpoint for a fixed
update count.

## Intervention and spatial interfaces

`model/intervention.py` supplies the actual state shift, basis-potential adapter,
population loss and full base-plus-adapter model. Load all its parameters from
the selected intervention artifact. Do not attach a tuned adapter to an unchanged
pretrained base. The released no-identity API enforces the shared condition slot.

`model/rectangle.py` supplies the original source-neighborhood construction,
native-data validator, model and joint objective. Construct `RectangleData` from
the `rectangle` directory with `coordinate_view="simulation_truth"`. Pass
explicit source `log_mass` to obtain a mass prediction; the loaded model returns
gene samples, position and log mass. The context is the mean gene state of 16
source-split neighbors. Use `JointObjective(data, transport_blur=0.05)` for the
current spatial objective.

Training these two tasks uses their separate losses; the temporal four-term loss
is not their objective. This release provides their model, loss, data and selected
weights. Historical cluster scheduling wrappers are not part of the public API.
